Rabtx UI sits on top of the shadcn layer in `@grid/ui` and adds the polish shadcn
leaves out: material, motion and edge detail.

```tsx
import { Button } from "@rabtx/ui/button";
```

## Where this starts

The Button here is currently the shadcn Button, copied verbatim and otherwise unchanged.
That is deliberate. It is the baseline, so every material decision that follows shows up as
a difference from a known starting point rather than arriving all at once.

The design direction — what `solid`, `detail`, `glass` and `terminal` each mean — lives in
[DESIGN.md](https://github.com/shabirkhan-dev/starter/blob/main/DESIGN.md), which is the
source of truth for the materials. Read it before changing a component.

## Status

Button only, at the shadcn baseline. Materials and motion land next, one step at a time.
