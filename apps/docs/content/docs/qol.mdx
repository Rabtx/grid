Consistency, fast feedback, and automation across TypeScript, Rust (the logger) and Bash.

## Cross-repo (Tier 1)

| Layer | What we use |
|-------|-------------|
| **Git hooks** | Lefthook: format, lint, typecheck, large-files, secrets, commit-msg (see `scripts/git-hooks/`) |
| **Task runner** | Bun scripts via `bun run <task>` (see root `package.json`) |
| **Editor consistency** | `.editorconfig`: LF, indent, charset, final newline |
| **CI** | `.github/workflows/ci.yml`: split quality gates (lint, typecheck, build, coverage tests, API contract tests, web e2e) on push/PR to `main` |
| **CD** | `.github/workflows/cd.yml`: staged deploy workflow template (staging on `main`, production on version tags) |
| **Dev Container** | `.devcontainer/`: reproducible env (Bun, Rust, shell tools). Reopen in Container; see `.devcontainer/README.md` |

## Per-language

| Language | Lint / format | Test / types |
|----------|----------------|--------------|
| **TS/JS** | oxlint + oxfmt (lint + format) | tsc (typecheck), Vitest |
| **Rust** | rustfmt, clippy (`bun run rust:lint`) | `bun run rust:test` (the logger crate) |
| **Bash** | shellcheck, shfmt | (bats optional) |

## One-command surface

From repo root:

- **`bun run format`** — oxfmt + scripts (shfmt) + cargo fmt
- **`bun run lint`** — workspace lint + scripts (shellcheck)
- **`bun run typecheck`** — TS only
- **`bun run test`** — workspace tests + script tests
- **`bun run test:coverage`** — TS coverage runs + all language tests
- **`bun run test:e2e:web`** — Playwright browser tests for `apps/web`
- **`bun run build`** — workspace build
- **`bun run rust:lint` / `bun run rust:test`** — the logger crate's clippy, fmt check and tests
