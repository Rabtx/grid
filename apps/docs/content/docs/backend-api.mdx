This page is the one place the NestJS API contract lives. The agent contract in
`.agents/agent-contract.md` points every role here: consumers read it before using an
endpoint, and backend updates it in the same commit as any public API change.

Base URL prefix: `/api/v1` (URI versioning). Auth uses JWT bearer tokens unless noted.

## What belongs here

- Every public endpoint: method, path, auth requirement, request and response shape.
- The response envelope, error shape and status-code conventions.
- Pagination, filtering and sorting conventions.
- Breaking changes, with a dated changelog entry below.

## What does not

- Implementation detail, internal service structure, database schema.
- Anything still being designed — raise a board card for that instead.

## Endpoints

Health and Swagger ship with the API. Auth, profile, and billing routes also live under
`/api/v1/*` — see Swagger at `/api/docs` for the full interactive list.

| Method | Path             | Auth        | Purpose        |
| ------ | ---------------- | ----------- | -------------- |
| `GET`  | `/api/v1/health` | none        | Liveness probe |
| —      | `/api/docs`      | none in dev | Swagger UI     |

### Projects and tasks

All project routes require `JwtAuthGuard` (bearer token). `:slug` is the project slug;
`:number` is the integer task number on that board.

| Method   | Path                                   | Auth | Purpose                               |
| -------- | -------------------------------------- | ---- | ------------------------------------- |
| `GET`    | `/api/v1/projects`                     | JWT  | List projects owned by the caller     |
| `POST`   | `/api/v1/projects`                     | JWT  | Create a project (`201`)              |
| `GET`    | `/api/v1/projects/:slug`               | JWT  | Get one project                       |
| `PATCH`  | `/api/v1/projects/:slug`               | JWT  | Update a project                      |
| `GET`    | `/api/v1/projects/:slug/tasks`         | JWT  | List tasks on a project board         |
| `POST`   | `/api/v1/projects/:slug/tasks`         | JWT  | Create a task (`201`)                 |
| `PATCH`  | `/api/v1/projects/:slug/tasks/:number` | JWT  | Update a task (including stage moves) |
| `DELETE` | `/api/v1/projects/:slug/tasks/:number` | JWT  | Delete a task (`204`)                 |
