## `apps/web`

The landing page (Next.js): what Grid is and how to install it. Signing in and everything after
happen in the console (`apps/console`), which `NEXT_PUBLIC_CONSOLE_URL` points to.

## `apps/console`

The product: a Vite and Solid 2 single-page app, the control plane where people and agents work.

## `apps/docs`

Fumadocs-powered documentation site for onboarding, architecture, and workflows.

## `apps/api`

The Grid API: Hono on Bun with Drizzle over PostgreSQL (schema and migrations in
`packages/db`): auth (2FA, passkeys, magic links, Google), sessions, profiles, projects, tasks,
notes, health, and billing (Stripe/Razorpay).

## Cross-app strategy

- Keep domain boundaries explicit.
- Share contracts and utilities through packages.
- Evolve each app independently while maintaining one quality bar.
