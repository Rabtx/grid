Welcome to the official documentation for the Grid monorepo.

This project combines modern tooling and a production-minded structure so you can ship the web
control plane, API, and docs site from one workspace.

## Why this repository

- Monorepo by default with Bun workspaces (`apps/*`, `packages/*`)
- Bun-first package and task management
- Shared TypeScript and UI packages across apps
- Built-in quality gates with oxlint, oxfmt and Lefthook
- Apps: the console, the API, the runner and launcher, web, and docs
