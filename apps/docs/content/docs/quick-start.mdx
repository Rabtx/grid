---

## Prerequisites

- Bun (latest stable)
- Git
- Node-compatible system dependencies for Next.js

## 1) Install dependencies

```bash
bun install
```

## 2) Install git hooks (recommended)

```bash
bun run prepare
```

This enables Lefthook checks for formatting, linting, type checks, and commit hygiene.

## 3) Run the workspace

```bash
bun run dev
```

Bun runs every workspace's `dev` task in parallel.

## 4) Open apps

With Docker up (or after `docker compose up -d postgres` for a host-only API/web setup):

- Web app: `apps/web` — http://localhost:3000
- API: `apps/api` — http://localhost:4000/api/v1/health
- Docs app: `apps/docs` — http://localhost:3002/docs

## 5) Validate quality before pushing

```bash
bun run lint
bun run format
bun run typecheck
```

If your change only touches one app, you can still run checks at the root to keep CI consistent.
