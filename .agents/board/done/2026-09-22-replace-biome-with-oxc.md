# Replace Biome with oxlint and oxfmt

**Role:** tooling
**Branch:** `agent/tooling/oxc-lint-format`
**Status:** open

## Why

Grid is moving its toolchain onto the Oxc stack. Biome currently does both linting
and formatting; oxlint (stable, 1.85) and oxfmt (0.70, Prettier-compatible) replace
it with the tools the rest of the intended toolchain already builds on.

## Scope

Replace `@biomejs/biome` with `oxlint` and `oxfmt` across the workspace.

1. Add `oxlint` and `oxfmt` as root devDependencies. Remove `@biomejs/biome` from
   the root and from every workspace package that lists it.
2. Generate the formatter config with `oxfmt --migrate=biome`, then **verify by hand**
   that it preserves what `biome.json` set:
   - `useTabs: true`, `printWidth: 100` globally;
   - the `apps/nest-api/**` override: single quotes, trailing commas `all`.
   Do not enable `sortImports` or `sortTailwindcss`. Those change code beyond
   formatting and are a separate decision.
3. Write `.oxlintrc.json` by hand. Map every rule that `biome.json` configures —
   including the whole `overrides` array — to its oxlint equivalent. The React and
   Next.js rules matter: `useExhaustiveDependencies`, `useHookAtTopLevel`,
   `noImgElement`, `noHeadElement`, `noDocumentImportInPage`, `noHeadImportInDocument`,
   `useGoogleFontDisplay`. Enable the import plugin (`--import-plugin` or the config
   equivalent) so ESM problems are still caught.
   The `packages/ui/src/components/*.tsx` override exists because those files are
   generated by the shadcn CLI and are not ours to reformat by hand. It excludes
   `bottom-bar.tsx`, `glass-card.tsx` and `typeset.tsx`, which **are** ours and must
   stay under the full rule set. Preserve that distinction exactly.
4. Update every `lint` / `lint:fix` / `format` script in the root and in each
   workspace package to call oxlint and oxfmt instead of biome.
5. Update `lefthook.yml` and anything under `scripts/` that invokes biome.
6. Update the editor config (`.vscode/`, `.editorconfig`) and any documentation that
   names Biome as the linter or formatter. Search the whole tree for `biome` — including
   `README.md`, `AGENTS.md`/`CLAUDE.md`, `.agents/`, `apps/docs/` content and CI workflows.
7. Delete `biome.json`.

## Constraints

- **Do not change application code to satisfy a new rule.** If oxlint reports findings
  that Biome did not, leave the code alone and list them in your report. Deciding
  whether to fix or suppress them is not part of this card.
- The one exception is pure reformatting from running oxfmt. That is expected.
- Do not add any other dependency. Do not touch `apps/`, `packages/` source files
  except through the formatter.
- Tabs, width 100. Conventional Commits, lowercase subject.

## Definition of done

All of these must actually be run, and their real output pasted in your report:

- `bun install` succeeds.
- `bun run lint` passes.
- `bun run typecheck` passes.
- `bun run test` passes.
- `bun run build` passes. **Run it. Do not skip it and do not report a cached
  replay as a fresh run** — use `turbo run build --force` if turbo reports a cache hit.
- `bun run architecture:check` passes.
- `git grep -in biome` returns nothing outside the lockfile.

## Report back

1. The rule-by-rule mapping table from `biome.json` to `.oxlintrc.json`.
2. **Any Biome rule with no oxlint equivalent** — name it and say what coverage was lost.
   This is the most important part of the report; do not omit it.
3. Any new oxlint findings you left unfixed.
4. The size of the formatting diff: `git diff --stat`.
