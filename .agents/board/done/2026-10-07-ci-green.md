## What

Every `main` commit fails CI (`test`: CI-only terminal socket tests) and CD (quality gate: `@grid/db` PGlite test timeouts, runner `ECONNREFUSED`, console preflight). `e2e-web` needs `test` (`.github/workflows/ci.yml:245-246`), so it never runs. CodeQL and dependency review need a paid feature on this private repo; the repo must stay private (paid icon pack), so those stay out of scope.

## Proposal or Ask

Find each CI-only failure's cause and fix it (not skip it); the CI and CD test jobs go green on a PR.

Found in the PM audit of `main` at `9237603`, 2026-10-07. Every claim was checked against the code
and the live data.

## Validation

- A regression test for the fix, failing before and passing after.
- The affected suites, plus root lint, typecheck, format and architecture checks.
- Never run tests against the live API on :4000 or the live chat database.

## Resolution

Fixed by claude, 2026-10-07, in #198. On the PR, CI's `test` passed, and `e2e-web` ran for the first time and passed. Lint, typecheck, build and api-contract also passed. CodeQL and dependency review fail only because they need a paid feature on a private repo, as scoped.
- **Real bug:** a shell's last fallback directory was the projects folder even when it didn't exist, so terminals couldn't open on a fresh machine (ENOENT from `posix_spawn`, an HTML 500). It now starts at home.
- **Racy tests:** the handshake tests counted the shell's echoed command line, so they now use a quoted needle and a trailing marker.
- **`@grid/db`:** the PGlite hook needed more than Bun's 5 s default on CI, so it now has 60 s.

Reproduced locally with an empty `HOME`: 4 link and environment tests fail on `main` and none here.
